# Chronicle.Plugin.OMDb

Metadata provider plugin for **OMDb**.

## Design Document

Full design documentation:
[docs/plugins/PLUGIN_OMDB.md](https://github.com/thegoddamnbeckster/Chronicle/blob/develop/docs/plugins/PLUGIN_OMDB.md)

## Supported Media Types

`movie`, `tv`

## Quick Start

1. `dotnet build`
2. Copy `Chronicle.Plugin.OMDb.dll` to your Chronicle `plugins/active/` directory
3. Restart Chronicle
4. Navigate to **Settings -> Plugins -> OMDb**
5. Configure required settings (see design doc)
